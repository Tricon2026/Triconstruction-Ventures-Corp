TRICON GROUP WEBSITE STARTER

Files:
- index.html: Responsive one-page corporate website prototype.

Preview:
1. Extract the ZIP file if you downloaded the ZIP.
2. Double-click index.html to open it in Chrome or another browser.

Suggested free hosting:
Google Sites is the easiest no-code option, but it will need to be rebuilt in its editor. Official guide: https://support.google.com/sites/answer/6372878

For this exact HTML file, GitHub Pages is a free static-hosting option for public repositories. Official guide: https://pages.github.com/
Basic steps:
1. Create/sign in to a GitHub account at https://github.com/
2. Create a new PUBLIC repository named tricon-group-website.
3. Upload index.html to the repository root and commit the file.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
6. Wait for the site to publish; GitHub will show the live URL in Pages settings.

Before publishing, replace or confirm:
- Company descriptions and service scope
- Official logos and approved photos
- Official phone numbers, email addresses, social links, and exact business addresses
- Any claims about services, facilities, and availability

The contact form is a front-end demo only. It does not transmit or store submissions; it prepares a text message for the visitor to copy.
